# 平台常见报错字典

本文档整理了 AgentMatrix 平台在控制台操作、模型网关、知识库检索、MCP/技能与开放接口中最常见的报错文案、产生原因与处理建议。

## 一、开放接口错误码（`/open/v1/*`）

错误响应统一格式为 `{"success": false, "message": "...", "data": {"code": "...", "request_id": "..."}}`，排查时可凭 `request_id`（响应头 `X-Request-Id`）在审计日志或后端日志中定位。

| HTTP / 错误码 | 报错含义与原因 | 处理方式 |
| --- | --- | --- |
| `401 key_invalid` | 未携带 `Authorization: Bearer`、API Key 不存在，或所属账号/签发人已被停用 | 检查请求头格式与 Key 是否完整；确认签发人账号未被停用，必要时在「开放与安全 → 开放凭证」重新签发 |
| `401 key_revoked` | 凭证已被手动停用/吊销，或签发人角色权限变更导致旧 Key 自动失效 | 在「开放与安全 → 开放凭证」重新签发新 Key 并替换调用方配置 |
| `401 key_expired` | 凭证已超过有效期，或轮换后超过 24 小时宽限期 | 使用轮换后的新 Key，或重新签发凭证 |
| `403 scope_missing` | 当前凭证缺少该接口所需的权限 scope（例如只有 `chat` 却调用了 `/agents`） | 在「开放与安全 → 开放凭证」签发勾选对应 scope 的凭证 |
| `403 agent_out_of_scope` | 未传 `agent_id`（且凭证绑定了多个智能体），或目标智能体不在凭证授权范围内 | 显式传入正确的 `agent_id` 或智能体编码，并在凭证配置中勾选该智能体 |
| `403 agent_not_running` | 目标智能体状态为「空闲中」或「已停用」，开放接口仅允许调用「运行中」的智能体 | 到「构建 → 智能体」找到对应智能体点击启用/发布，使其处于「运行中」状态 |
| `403 ip_not_allowed` | 调用方出口 IP 不在凭证的 IP 白名单内 | 在「开放与安全 → 开放凭证」核对并补充调用方出口 IP |
| `403 client_required` / `client_not_allowed` / `client_expired` | 开启了终端强制管控，但请求未带 `X-Client-Id`、终端未登记/待审批/已停用或已过期 | 请求头补充 `X-Client-Id` 与 `X-Client-Type`，并由管理员在「开放与安全 → 接入终端」批准启用 |
| `403 kill_switch` | 该开发者名下的开放调用已被护栏策略「紧急停用」 | 在「开放与安全 → 护栏策略」关闭紧急停用开关 |
| `403 outside_allowed_hours` | 当前时间不在护栏策略允许的调用时段内 | 在「开放与安全 → 护栏策略」调整允许调用时间段（格式 `HH:mm-HH:mm`） |
| `403 dependency_invalid` | 智能体绑定的知识库已被删除、停用，或创建人对其使用授权已被撤销 | 到智能体编排页解绑失效知识库，或联系知识库所有者重新授予 USE 权限 |
| `422`（输入安全拦截） | 用户输入命中敏感词或提示词注入检测规则 | 检查用户输入内容；如属误拦，在「开放与安全 → 护栏策略」调整敏感词表或策略 |
| `429 rate_limited` | 触发每分钟请求数（RPM）限流 | 根据响应头 `Retry-After` 退避重试，或在凭证/终端/护栏策略中适当调高 RPM 上限 |
| `429 quota_exceeded` | 超出开发者、凭证或终端的每日 Token 配额 | 等待次日重置，或在「开放与安全」对应配置中调高每日 Token 配额 |
| `501 not_supported` | 调用了暂不支持的 `POST /open/v1/chat-messages/{taskId}/stop` | 流式对话需中途停止时直接断开 HTTP/SSE 连接即可 |

## 二、模型网关与通道报错

| 报错文案 / 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| `请先配置 API Key 后再启用通道` / `鉴权失败，请检查 API Key 是否有效` | 通道未填写 API Key，或密钥无效、已过期、账号欠费 | 到「管理 → 模型网关 → 大语言模型」重新填写有效 API Key 并点击「测试连接」 |
| `无法连接供应商` / `Connect timed out` | 目标地址不可达、内网机器未开机/IP 变更、端口未放行或 Ollama 未监听 `0.0.0.0` | 检查网络连通性与地址端口；内网 Ollama 需配置 `OLLAMA_HOST=0.0.0.0`；如服务器 IP 变更请同步修改网关中的地址 |
| `不允许访问本机或内网地址`（SSRF 拦截） | 生产环境（`prod`）默认禁止模型网关或 MCP 访问内网私有地址 | 生产环境若确需访问内网模型/MCP 服务，由运维在配置中显式放开内网白名单，或为单个 MCP 服务手动放行 |
| `HTTP 400 ... tools is not supported` | 所选模型通道不支持 Function Calling（工具调用） | 在「管理 → 模型网关 → 大语言模型」关闭该通道的「支持工具调用」开关，平台会自动跳过工具与技能注入 |
| `第三方大模型返回业务错误 (code=...)` / `未能从响应路径 [...] 中提取到回答文本` | 自定义 HTTP 通道的业务状态码非预期，或 JSON 提取路径（如 `data.result`）与实际响应不一致 | 在该自定义 HTTP 通道配置中核对业务成功码、回答提取路径和 Body 模板，点「测试连通性」验证 |
| `当前还没有可用的大模型通道` | 没有任何已启用且配置好密钥的通道 | 超级管理员到「管理 → 模型网关 → 大语言模型」至少启用一个可用通道并设为默认通道 |
| `调用动态 Embedding 接口失败` / `向量接口返回的数据中没有 embedding 数组` | 激活的向量模型地址不通、鉴权失败、模型名不是 Embedding 模型，或接口格式不兼容 | 到「管理 → 模型网关 → 向量模型」检查地址、Key/自定义请求头和模型名，先点击「测试连接」通过后再使用 |
| `自定义请求头最多 N 个` / `请求头「...」由系统自动设置，不能自定义` | 填写了重复请求头、受保护系统头（如 `Host`/`Content-Length`）、超长或含换行符的值 | 删除系统保留头与重复头，确保请求头名称仅含字母数字和 `- _ .` 且无换行 |

## 三、知识库、文档与索引报错

| 报错文案 / 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| `同一知识库已存在相同内容的文件` | 上传的文档与该知识库已有文档 SHA-256 相同，触发重复上传拦截 | 无需重复上传；如需重新解析切片，请先删除旧文档或使用「重建索引」 |
| `不支持的文件格式` / 文件大小超限 | 上传了 `.doc`、`.pptx`、图片等不支持格式，或单文件超过 15MB、单批超过 5 个 | `.doc` 请另存为 `.docx`；扫描件/图片转 PDF 并配置 OCR；拆分大文件或分批上传 |
| `扫描件待识别` / 文档内容为空 | 上传的是纯图片扫描版 PDF，但尚未配置 OCR 服务 | 超级管理员到「管理 → 模型网关 → OCR 识别」配置并激活本地或在线 OCR 后，对知识库执行「重建索引」 |
| `Dify 服务器 Base URL 不能为空` / `Dify 引擎未就绪` | 创建 Dify 知识库前未在模型网关配置并测通 Dify 引擎 | 到「管理 → 模型网关 → Dify 知识引擎」填写地址与 Dataset API Key 并测试通过 |
| 更换向量模型后检索不到内容 / 维度不匹配 | 切换了不同维度的 Embedding 模型，旧切片向量与新查询向量不可比 | 进入对应自建知识库详情页，点击「重建索引」用新向量模型重新生成文档和 FAQ 向量 |

## 四、权限、账号与资源保护报错

| 报错文案 / 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| `系统公共预置资产受平台保护，仅超级管理员可直接修改` | 开发者尝试直接编辑、启停或删除系统公共智能体/模板 | 点击「复制」创建属于自己的个人副本后再修改；或联系超级管理员调整 |
| `权限不足：无权修改其他开发者的个人智能体` / `无权绑定未获得 USE 授权的知识库` | 尝试操作他人私有资源，或未获得目标知识库的 USE 使用授权 | 联系资源所有者在权限设置中授予查看/运行/使用权限，或改用自己创建的/系统公共资源 |
| `只读观察员无权创建/修改...` | 当前登录角色是只读观察员（VIEWER），只能浏览和查看监控 | 联系超级管理员到「管理 → 用户」将账号角色调整为「开发者」 |
| `账号已被管理员禁用` / `临时密码已过期` | 账号被停用，或新建/重置后的临时密码超时未改 | 联系超级管理员在「管理 → 用户」重新启用账号或重置临时密码 |
| `原密码校验失败` / `新密码长度不能少于 6 位` | 个人中心改密码时旧密码输入有误或新密码过短 | 核对当前密码，确保新密码至少 6 位 |
| `工作时间段格式不正确，应为 HH:mm-HH:mm` | 护栏策略中允许调用时段格式填写错误 | 按 24 小时制填写，例如 `08:00-22:00` |
