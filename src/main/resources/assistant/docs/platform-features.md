# 平台功能使用说明

给平台管理员、运营人员看：控制台各模块管什么、怎么配置、哪些设置会影响效果和成本。

---

## 1. 模型网关（仅超级管理员）

侧边栏「管理 → 模型网关」展开后有五个子页面（大语言模型、向量模型、Rerank 模型、OCR 识别、Dify 知识引擎），每个子页面后的状态点含义：绿色正常，橙色需要处理，灰色未启用（可选项）。

### 1.1 大语言模型

智能体对话使用的模型通道。

| 设置 | 作用 |
| --- | --- |
| 通道 | 内置 DeepSeek、通义千问、腾讯混元、字节豆包、智谱 GLM，也可添加自定义 OpenAI 兼容通道、Ollama 或自定义 HTTP 模板通道。密钥 AES-GCM 加密存储 |
| 调度开关 | 关闭的通道不参与路由 |
| 能力标记 | 可设置「支持工具调用」和「上下文窗口（tokens）」。不支持工具调用的通道自动跳过工具与技能；平台按上下文窗口自动收缩知识库与历史对话 |
| **默认通道** | 智能体选择「跟随平台默认」时走这个通道 |
| **降级备用** | 默认通道调用失败时改用的通道 |
| **自动故障转移** | 勾选后，失败时才会切到降级备用通道；不勾选则直接报错 |
| **AI 助手** | 平台内置 AI 助手专用的通道和模型，不设置则跟随默认通道 |

切到备用通道时，调试窗口的回答下方会提示主通道失败，「概览」和智能体的「监控」页也会显示切换次数。开放接口的返回不包含这项信息，失败原因看后端日志。

**选路顺序**：智能体自选主通道（若配置且当前可选）→ 默认通道 → 与智能体指定模型匹配的就绪通道 → 任意一个就绪通道。超时和重试次数在通道上设置，未设置时用全局默认值（30 秒）。

**智能体自选通道**：在调试页右上角为单个智能体选择主通道（及模型）和备用通道，发布上线后生效，未发布的修改只对当前窗口有效。

| 规则 | 说明 |
| --- | --- |
| 可选条件 | 已启用、配置了 API Key、最近一次连通测试通过 |
| 自选通道不可用 | 改用平台默认通道，回答下方提示原因，智能体列表的「调度模型」标黄 |
| 自选备用通道 | 不受「自动故障转移」开关影响；切换时使用该通道的默认模型 |
| 主备相同 | 不允许，保存时报错 |
| 调试页「测试」 | 真实调用一次所选模型，只返回结果，不改动通道的测试状态；每个账号 3 秒内一次，只读观察员不能测试 |

平台全局的默认通道和降级备用不要求最近一次连通测试通过，规则与以前一致。

**自定义通道的附加配置**（「配置」弹窗里的自定义配置 JSON）：
- `headers`：用自定义请求头鉴权，代替 `Authorization: Bearer`（例如中转服务要求的 `app_id`）。
- `"webSearch": true`：该通道默认开启服务端联网搜索。
- 自定义 HTTP 协议支持灵活配置请求地址、请求方式、Headers、Body 模板（`{{prompt}}`、`{{user_message}}`、`{{system_prompt}}`）、业务成功码、回答提取路径和错误提取路径。

### 1.2 向量模型

自建知识库切片向量化与语义检索使用的 Embedding 模型。
- 全平台**同时只生效一个**。
- 支持 OpenAI 兼容的 `/v1/embeddings` 接口（末尾已是 `embeddings` 时原样调用），支持自定义请求头鉴权。
- **更换向量模型后，已入库的文档和 FAQ 需要点「重建索引」**，否则新旧向量不可比导致检索失准。
- 未激活向量模型时平台退回内置特征投影，语义检索效果明显变差。

### 1.3 Rerank 模型

自建知识库选择「Rerank 模型」排序时调用，对候选切片做二次排序（可选）。
- 全平台同时只生效一个。地址末尾是 `rerank` 或 `reranks` 时原样调用，否则自动拼接 `/rerank`。
- 只有混合检索并选择「Rerank 模型」的知识库才会调用，每次最多重排 100 个候选切片，失败或超时自动退回融合排序且不写语义缓存。
- 切换或修改生效配置后，全部知识库的语义缓存会自动清空。Dify 知识库的 Rerank 在 Dify 侧配置。

### 1.4 OCR 识别

识别扫描版 PDF 和图片里的文字（支持本地 PaddleOCR 与在线云端 OCR，可选）。未配置时扫描件标记为待识别，不影响其他文档入库。

### 1.5 Dify 知识引擎

对接外部 Dify 实例，在平台内管理 Dify 知识库（可选）。接入后（或库里已有 Dify 知识库时）侧边栏才出现「Dify 知识库」；新建 Dify 知识库要求引擎已通过连通性测试。

## 2. 知识库

### 2.1 两种引擎

| 对比项 | 自建知识库 | Dify 知识库 |
| --- | --- | --- |
| 解析、切片、向量化 | 平台本地完成 | 交给外部 Dify |
| 向量模型 | 模型网关里生效的向量模型 | Dify 中配置的模型 |
| 前提 | 激活一个向量模型 | 在模型网关接入 Dify 并测试通过 |

同一智能体只能绑定同一引擎类型的知识库，不能混绑自建和 Dify 知识库。

### 2.2 支持的文件格式（自建知识库）

单个文件不超过 **15 MB**，一次最多上传 **5 个**文件；同一知识库拒绝重复上传相同内容的文件。
- `TXT / MD / MDX / MARKDOWN / VTT / PROPERTIES`：纯文本，自动识别 UTF-8 / GBK 编码。
- `PDF`：PDFBox 提取文字层，自动去除页眉页脚和目录并识别章节标题；文字过少时判定为扫描件需 OCR。
- `DOCX`：按原顺序读取段落和表格，保留章节标题。
- `XLSX / XLS / CSV`：逐工作表按行配对表头，公式取计算结果，跳过隐藏工作表。
- `HTML / HTM`：去脚本样式，保留标题层级、列表和表格。
- 不支持旧版 `.doc`、`.pptx` 等格式，上传会被拒绝。

### 2.3 检索设置与重建索引

- 切片默认每段 500 字、重叠 80 字，并自动带上「文档名 › 章 › 节」上下文标题用于向量化和关键词检索。
- 检索方式默认**混合检索**（pgvector HNSW 向量 + Jieba 中文分词内存 BM25，RRF 融合，默认权重 5:5），结果按内容自动去重；召回数 Top K 默认 3，相似度阈值默认 0.5。
- 详情页提供「重建索引」（同步重建文档切片、FAQ 和当前激活的向量模型）、「召回测试」与「清空语义缓存」。
- **FAQ（精准问答对）**：固定高频问答优先命中，支持上传附图，开放接口在相似度达标时随回答返回附图 URL。

### 2.4 检索评测（自建知识库）

在知识库详情的「检索评测」页准备 30～50 道带答案原文的题目（支持 Excel 批量导入），选择检索方式与排序方式运行，获取前 N 命中率、前 5 命中率、前 10 召回率与排序质量（NDCG@10），并可设基准记录对比。

## 3. 智能体、工具与技能库

### 3.1 智能体状态与编排

- 状态只有三种：**运行中**、**空闲中**、**已停用**。仅「运行中」可被开放接口调用，空闲中/已停用返回 `agent_not_running`。
- 编排页（调试页）支持：提示词草稿与发布上线、最近 100 个提示词版本对比与一键回滚、变量（`{{input}}`、`{{system_time}}`）、主备通道路由自选、温度/Top P/Max Tokens/记忆轮数（0～10）/思考模式（OFF/AUTO/ON）、知识库使用方式（先检索后回答 / 模型自主检索）、技能关联、工具勾选、访问 API 与日志/监控。
- **知识库使用方式**：「先检索后回答」每条消息（包括寒暄）都检索一次；「模型自主检索」由模型判断要不要调用 `search_knowledge`，一次回答最多 3 次，平台在系统提示里要求业务问题必须先检索、寒暄闲聊不检索，但不强制执行，效果取决于模型。通道不支持工具调用时自动退回先检索后回答。调试窗口会列出每次回答的检索查询词。
- **提示词缓存**：系统提示词放 system，当前时间与知识库片段放最后一条用户消息，支持提示词缓存的模型可复用固定前缀；提示词中尽量不要手动写 `{{system_time}}` 以免缓存失效。

### 3.2 工具与 MCP 服务

- 「构建 → 工具」统一管理时间工具、DeepSeek 联网搜索（约 0.005 元/次）、博查联网搜索（约 0.036 元/次，需配博查 Key）、自定义 HTTP 工具，以及顶部可调的「单次回答最多调用工具轮数」（默认 5 轮，1～10）。
- **MCP 服务**：仅超级管理员可在「工具 → MCP 服务」接入远程 Streamable HTTP / SSE MCP 服务、刷新工具并逐个审核启用；上游工具定义变化时自动停用并提示重新审核。
- 工具页提供今日/本月调用次数、成功率、平均耗时、14 天趋势与按单价估算的本月费用。

### 3.3 技能库（Skill）

「构建 → 技能库」用 Markdown 编写可复用处理流程，支持版本历史及 `SKILL.md` / zip 导入导出。智能体关联技能后，平时仅注入简短目录，模型判断适用时自动调用 `load_skill` 按需加载完整步骤。

## 4. 成本与延迟参考

一次带知识库的问答，输入约 1500～4000 Token，输出约 100～500 Token。主要影响因素：联网搜索（+2000～6000 输入 Token、慢 3～5 秒）、上下文记忆（每多 1 轮 +300～500 Token）、Top K、思考模式（FAQ 场景建议关闭）与输出长度。

---

## 5. 开放与安全

「管理 → 开放与安全」（非超管位于「规则与安全 → 开放与安全」）包含：风险总览、接入文档（含在线调试）、开放凭证、接入终端、用量统计、护栏策略、审计日志、账号对接与告警规则。
