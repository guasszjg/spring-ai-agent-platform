# AgentMatrix 平台使用文档

本文档是 AgentMatrix 企业级智能体平台的使用说明，供平台内置的 AI 助手检索后回答使用问题。
界面左侧菜单分为四组：监控（概览）、构建（智能体、场景模板、工具、技能库）、数据（自建知识库、Dify 知识库）、管理（模型网关、用户、角色与权限、助手评测、开放与安全；非超级管理员该组显示为「规则与安全」，仅保留开放与安全）。

## 角色与权限

平台有三种角色：

- **超级管理员**：拥有全平台权限，包括模型网关、用户管理、角色与权限、开放与安全等治理功能，可以管理系统公共资源。
- **开发者**：可以创建、调试并管理属于自己的智能体、知识库与场景模板；可以使用系统公共资源和别人授权给自己的资源。
- **只读观察员**：只能查看被授权的智能体与知识库的元数据和监控指标，不能创建、编辑、调试。

「用户」和「角色与权限」菜单仅超级管理员可见。新建用户或重置密码后，用户首次登录需要先修改临时密码，临时密码过期后需联系管理员重新重置。

资源分为三类归属：我创建的（我的）、系统公共（超级管理员创建，所有人可见可用）、他人共享给我的（通过授权获得查看、运行或使用权限）。系统公共智能体只有超级管理员可以修改，开发者可以点击「复制」得到一份属于自己的副本再修改。

## 概览

「监控 → 概览」展示当前账号范围内的用量：超级管理员看全站数据，其他角色看本人创建的智能体与本人的 AI 助手对话。

- Token 总量、输入 / 输出 Token、估算成本，可切换今天、近 7 天、近 30 天；
- Token 趋势、模型占比、调用排行（所选时间内的调用次数，只含现存智能体）、按分类的平均响应时延。

AI 助手自身消耗的 token 也计入概览的用量与成本；超级管理员看到的用量和成本包含已删除智能体。估算成本只算大模型，不含向量化、重排和联网搜索。

主通道失败、切到备用通道时，调试窗口的回答下方会提示，概览也会显示所选时间内的切换次数。

## 智能体

### 创建智能体

在「构建 → 智能体」点击新建，填写：

- **名称**：必填；**唯一业务编码（code）**由系统自动生成，创建后不变，开放 API 调用时可以用编码指定智能体；
- **分类**：代码研发、运维架构、产品策划、知识库客服、数据分析、内容创作、通用智能；
- **模型**：新建的智能体跟随平台默认通道；创建后可在调试页右上角为它单独选择通道和模型（见下文「模型通道」）；
- **系统提示词（System Prompt）**：定义智能体的角色、能力边界与回答风格；
- 温度（temperature）、描述、标签等。

也可以从「场景模板」一键套用行业模板创建，再按需修改。

### 智能体列表

列表支持按范围（全部 / 我的 / 系统公共）、分类、运行状态和关键词筛选，提供卡片与列表两种视图。卡片上可以调试、编辑、复制、启停，并显示累计调用次数和平均响应耗时。点击智能体 ID 可以一键复制，开放 API 调用时需要用到。

「调度模型」显示每个智能体实际使用的通道和模型：自选了通道的显示自选的，没选的显示平台默认通道。自选的通道当前不能用时标签变为黄色，显示的是改用后的平台默认通道；鼠标悬停可以看到是自选还是跟随平台，以及备用通道。

智能体只有三种状态：**运行中**、**空闲中**、**已停用**。已停用的智能体不能被调用，包括通过开放 API 的请求。在卡片上点击启停按钮即可切换。

### 编排与调试

在智能体卡片上点击「调试」进入编排与调试页面，左侧是编排区，右侧是调试预览：

- **提示词**：编辑系统提示词，支持 AI 自动生成或优化。左侧编辑的是草稿，右侧调试使用草稿，点「发布上线」后才成为线上提示词；
- **提示词版本**：每次发布（以及创建、编辑、AI 助手修改）都会自动记录一个版本，发布时可以填写版本说明。点提示词卡片上的「版本」可以查看历史版本、与当前草稿逐行对比、载入到草稿，或一键回滚为线上版本（回滚会生成一个新版本，不会删除历史）。每个智能体保留最近 100 个版本；
- **变量**：支持内置变量与自定义变量，点击任意变量标签即可一键插入到提示词光标处：
  - **内置变量**：`{{input}}`（本轮用户输入）、`{{system_time}}`（北京时间+星期）、`{{today}}`（今日日期+星期）、`{{date}}`（今日日期）等，由服务端直接读取系统时钟注入，**无需开启时间工具**即可生效；
  - **自定义变量**：支持新增单行文本、多行文本、下拉选项、数字 4 种类型，可设默认值、输入提示与必填校验；配置后，调试页右侧与免登录分享页顶部自动展示可折叠的变量表单，开放接口 `POST /open/v1/chat-messages` 可通过可选 `inputs` 字段动态传值（未传时自动回退默认值，适合多门店/多终端复用同一智能体）；
- **模型与通道路由**：调试页右上角可为智能体单独选择主通道、具体模型和备用通道，也可以选择「跟随平台默认」，详见下文「模型通道」。智能体还支持配置上下文记忆轮数（0～10 轮，默认关闭）、**记忆压缩**开关（开启上下文记忆后可勾选，默认关闭；开启后超出轮数的早期对话会在每轮结束后后台异步浓缩为摘要保存，不拖慢首字且保护大模型前缀缓存，在「日志」抽屉中可查看记忆摘要）和思考模式（OFF / AUTO / ON）；
- **知识库**：绑定一个或多个知识库，可选「先检索后回答」（默认）或「模型自主检索」，区别见下文「知识库使用方式」；
- **技能（Skill）**：关联技能库中的技能后，系统提示只列技能目录，对话时由模型按需调用 `load_skill` 加载完整步骤；
- **工具**：开启时间工具、联网检索、自定义 HTTP 工具以及已审核启用的 MCP 工具，模型会按需自动调用。在「构建 → 工具」中停用某个平台工具后，智能体调试页将不再显示该工具，历史已勾选的停用工具也会在刷新后自动隐藏并在服务端拦截执行；
- 右侧调试区顶部提供「对话预览 | 调用链路」两个子标签页，对话时显示工具调用过程、加载的技能、自主检索查询词、FAQ 附图与视频、响应耗时与 token 消耗；
- **调用链路（性能与卡点排查）**：调试区右上角提供「链路开 / 链路关」开关（**默认关闭**，零额外开销）。排查回复慢或卡住时点击开启，流式生成过程中会在等待气泡下方实时滚动当前执行节点，切到「调用链路」子标签页或点击回复底部的「调用链路」按钮即可查看完整耗时瀑布图（权限准备、语义缓存、查询改写、向量模型编码、向量与全文召回、Rerank 重排、工具调用、大模型各轮次首字延迟 TTFT 与 Token 消耗），自动标注主要耗时或异常中断节点，并支持一键复制 JSON。

### 模型通道

调试页右上角的通道按钮显示智能体当前使用的主通道和模型，点击打开选择面板：

- **主通道 / 备用通道**两个标签页，第一项都是「跟随平台默认」，旁边显示平台当前的默认通道（或降级备用通道）。选了主通道后，可以在下方选择该通道的具体模型；备用通道使用该通道的默认模型；
- **能选的通道**：在「模型网关 → 大语言模型」中已启用、配置了 API Key，并且最近一次连通测试通过。其他已启用的通道列在「不可选的通道」里，并写明原因（未启用、未配置 API Key、还没有做连通测试、最近一次连通测试未通过）；
- 每个通道显示是否支持工具调用、上下文窗口和模型网关最近一次测试的时间。选择不支持工具调用的通道时，智能体的工具、技能和模型自主检索都不会生效；
- **测试**：点通道上的「测试」会用当前选的模型真实调用一次，显示能否使用和耗时，失败时显示模型服务返回的原因。测试只返回结果，不会改动模型网关里该通道的测试状态；同一账号 3 秒内只能测一次；只读观察员不能测试；
- **生效范围**：在面板里的修改只对当前窗口的调试对话生效，按钮上显示「草稿」；刷新或重新进入页面会回到已发布的设置。点「发布上线」后保存到智能体，开放接口等线上调用从此按新设置走。发布弹窗会列出通道从什么改成了什么；
- **主备不能相同**：备用通道里已作为主通道的那个不能选；把主通道改成原来的备用通道时，备用通道自动改回跟随平台；
- **自选的备用通道**不受平台「自动故障转移」开关影响，主通道失败时都会切过去；选「跟随平台默认」时按平台的降级设置；
- **自选的通道后来不能用了**（被停用、删除、测试失败或删除了 Key）：对话会自动改用平台默认通道，回答下方提示原因，通道按钮和智能体列表的「调度模型」标为黄色。到调试页重新选择并发布即可恢复；
- 开发者和超级管理员都可以为自己能管理的智能体选择通道。

### 访问入口

调试页的「访问入口」标签页分两块：

- **Web 应用**：分享链接，生成一个免登录的聊天页地址（`/chat/链接码`），发给客户演示或请同事试用，对方不需要平台账号；
- **后端服务 API**：开放接口的地址、凭证和在线调试，用于开发者自己接入（见「开放与安全」）。

**新建分享链接**：点「新建链接」，填写：

| 设置 | 说明 | 默认 |
| --- | --- | --- |
| 名称 | 例如「给 A 客户演示」「门店试用」，只给自己看 | 必填 |
| 访问方式 | 访问码：访客要输入访问码才能对话；公开：拿到链接就能对话（需要超级管理员在「构建 → 工具」打开「允许公开分享链接」） | 访问码 |
| 访问码 | 不填自动生成 6 位数字；也可以自己填 4～32 位字母或数字。**只在新建和重新设置时显示一次**，请及时复制给访客 | 自动生成 |
| 有效期 | 1 天、7 天、30 天或自定义日期，最长 365 天 | 7 天 |
| 对话次数上限 | 访客每发一条消息算一次，用完链接自动失效 | 200 次 |
| token 总量上限、访客数上限 | 用完或满员后链接失效 / 新访客进不来，填 0 表示不限 | 不限 |
| 每个访客每分钟消息数 | 防止刷接口 | 10 条 |
| 标题、欢迎语、示例问题 | 聊天页上显示，示例问题访客点击即可发送 | 标题用智能体名称 |
| 「对话会被记录」提示 | 在聊天页底部显示 | 显示 |

创建后会弹出链接地址、访问码和二维码，手机扫码即可打开。

**管理链接**：链接列表显示每个链接是否可用、到期时间、对话次数、token 用量、访客数和最近使用时间，可以：

- **复制链接 / 二维码**；
- **编辑**：修改名称、显示内容、各项上限，延长有效期（从现在起重新计算）或重新设置访问码，链接地址不变；
- **停用 / 启用**：立即生效，停用后正在对话的访客发下一条消息就会被拒绝；
- **重置**：生成新的链接地址，旧地址和已进入的访客立即失效，访问码不变。链接泄露时使用；
- **访客记录**：查看每个访客的对话内容，用于演示后复盘；
- **删除**：链接立即失效，访客的对话记录仍保留在智能体日志里。

链接 24 小时内到期时，智能体列表上会显示「链接即将到期」，点击可直接跳到这里延期。

**访客看到什么**：只有标题、欢迎语、示例问题和对话内容，看不到提示词、知识库、模型和通道。链接过期、用完、被停用、智能体被停用时，访客页面只显示「链接已失效，请联系提供方」，不显示智能体的任何信息。访客可以多轮对话、点「停止」中止回答、查看自己的历史对话；进入后 2 小时内刷新页面不用重新输入访问码。

**安全与计费**：

- 访问码连续输错 5 次，该访客锁定 15 分钟；
- 对话走开放接口的同一条链路，护栏（敏感词、个人信息脱敏、提示词注入检测）照常生效，用量计入智能体统计和平台概览；
- 每个链接内部使用一个只能调用该智能体对话的凭证，不会出现在「开放凭证」列表里，重置或删除链接时一起作废；
- 拿到链接的人可以通过提问看到知识库内容，给外部客户的智能体请只关联可以公开的知识库。

开发者和超级管理员可以管理自己能管理的智能体的分享链接，只读观察员不能。AI 助手可以查询分享链接的状态和用量、停用链接；新建链接、修改访问码和有效期请在页面上操作。

### 知识库使用方式

| | 先检索后回答（默认） | 模型自主检索 |
| --- | --- | --- |
| 什么时候检索 | 每条消息都先检索一次，包括「你好」这类寒暄 | 由模型判断，需要时调用 `search_knowledge` 工具 |
| 一次回答检索几次 | 固定 1 次 | 0～3 次，没查到可以换个说法再查，问题涉及多个方面可以分别查 |
| 查询词 | 用户的原话 | 模型提炼的关键词，保留型号、文件名、端口号等原词 |
| 对模型的要求 | 无 | 通道要支持工具调用 |

模型自主检索时，平台在系统提示中告诉模型：问到产品、设备、软件、业务、流程、规定、参数、故障处理等具体问题时必须先检索再回答，不能凭自己的知识作答；只有寒暄、问身份和与业务无关的闲聊才不检索；检索后仍没有相关资料时如实告诉用户。

注意：

- **这是给模型的要求，平台不强制**。模型没有遵守（例如业务问题没有检索就直接回答）时平台不会拦截。DeepSeek 等大模型通常可靠，小模型容易漏查或乱查；
- **通道不支持工具调用时自动退回「先检索后回答」**，例如板端小模型通道，这时每条消息仍会检索；
- 调试窗口每条回答会列出本次检索使用的查询词，没有列出说明模型这次没有检索；
- 需要业务问题一定检索时，使用「先检索后回答」。

### 日志与监控

在智能体上可以查看调用日志（每次对话的输入、输出、模型与耗时）和监控统计（调用量、成功率、耗时趋势）。开启过「调用链路」的对话（无论是调试页开启还是超管临时开启开放接口链路记录），在日志抽屉的智能体回复下方都会出现「调用链路 (N 步)」按钮，点击可展开当时的耗时瀑布图与命中片段。智能体"没有回复"或"回答慢"时，先看日志中的错误原因与调用链路。

## 场景模板

「构建 → 场景模板」提供按行业预置的智能体模板（包含名称、分类、系统提示词、模型参数等）。选择模板可以一键创建智能体。开发者也可以创建自己的模板，超级管理员可以维护系统公共模板。

## 工具

「构建 → 工具」管理所有智能体共用的平台工具：

- **时间工具**：获取当前时间、时区转换、时间戳转换、星期计算等；
- **联网检索（博查搜索）**：用于查询最新新闻、实时天气等互联网信息，需要配置博查 API Key；
- **自定义 HTTP 工具**：填写请求地址、方法、参数说明，让智能体调用你自己的业务接口；
- **MCP 服务**：超级管理员可在「工具 → MCP 服务」添加远程 MCP 服务（支持 Streamable HTTP 与 SSE，Bearer Token 或自定义请求头鉴权），测试连接并拉取工具列表；工具需经管理员审核启用后，开发者才能在智能体中选用。上游工具定义变化时会自动停用并提示重新审核。

工具在这里统一维护，在智能体编排页中按需开启；在工具管理页停用任意平台工具后，该工具会立即从智能体调试页隐藏且后端拒绝调用。

页面顶部有三项平台设置：「单次回答最多调用工具轮数」（默认 5 轮，1～10 轮）、「允许公开分享链接」（仅超级管理员，默认关闭；打开后分享链接可选公开方式，关闭后已有公开链接立即失效），以及「记录开放接口调用链路」（仅超级管理员，**默认关闭**，保证客户端 API 与免登录分享零额外开销；排查线上慢请求时临时打开，客户端无需改动任何请求/响应字段，服务端静默落库后即可在智能体「日志」中查看该请求的调用链路）。

## 技能库

「构建 → 技能库」把特定场景的处理流程写成可复用的 Markdown 技能（Skill）：

- 技能包含名称、触发场景描述、详细步骤（Markdown）和所需工具，支持版本历史记录，以及社区标准的 `SKILL.md` / zip 导入与导出；
- 权限与知识库一致：开发者管理自己的技能，超级管理员管理全部及系统内置技能，系统内置技能所有人可用；
- 在智能体调试页关联技能后，日常对话只在系统提示中附带技能目录，模型判断适用时自动调用 `load_skill` 按需加载完整步骤（要求所选模型通道支持工具调用）。

## 知识库

「数据 → 知识库」管理企业私有知识，智能体绑定后回答时会检索知识库内容。

### 两种引擎

- **平台内置引擎**：文档在平台本地解析、切片（带「文档名 › 章节」上下文标题）、向量化，支持向量 + BM25 中文分词混合检索、父子分块、Rerank、语义缓存；详情页支持「重建索引」。**必须先在「模型网关 → 向量模型」中配置并激活一个向量模型**，否则只能做字符级近似匹配，语义检索效果很差。
- **Dify 外部引擎**：文档存放在外部 Dify 服务中。需要先在「模型网关 → Dify 知识引擎」中配置地址与 API Key 并测试连接成功，才能创建 Dify 知识库。

### 文档与 FAQ

- 支持上传 Markdown、PDF、DOCX、TXT、HTML、CSV、XLSX 等格式，每批最多 5 个文件、单个文件不超过 15MB；扫描件与图片可通过 OCR 识别。
- 可以维护 FAQ（高频问答对），问答对会优先命中，适合客服场景。每条 FAQ 支持挂载**图片与视频附件**（不参与向量检索，回答命中且相似度达标时随回答一并返回）：
  - **图片**：最多 **9 张**（本地上传单张 ≤ 10MB，与粘贴 `http(s)://` 联网图片链接合并计数合计不超过 9 张）；多图在调试页和免登录分享页默认每 3 秒自动轮播切换（悬停暂停、点击查看大图灯箱）；
  - **视频**：最多 **3 个**（支持本地上传 ≤ 500MB 的 `MP4 / WEBM / MOV` 并显示实时进度条，也支持直接粘贴外部 OSS / CDN `http(s)://` 视频直链）；在调试页和免登录分享页自动播放（浏览器限制有声自播时自动静音开播并提供一键开声），多视频播完自动连播切换下一个。
- 自建知识库提供检索评测：准备一批带答案原文的题目（可从 Excel 批量导入），选择检索方式和排序方式运行，得到前 N 命中率（N 是知识库的 Top K）、前 5 命中率、前 10 召回率和排序质量，并能和基准记录对比，用来判断改配置有没有用；
- 提供召回测试：输入一个问题，查看能检索到哪些切片及其得分，用于调整检索参数（TopK、相似度阈值、向量与关键词权重）。

### 检索不到内容时的排查

1. 知识库是否为空（没有文档也没有 FAQ）；
2. 平台内置引擎：是否已激活向量模型，向量模型最近一次测试连接是否成功，更换向量模型后是否重建过索引；
3. Dify 引擎：Dify 知识引擎是否配置并测试连接成功；
4. 用召回测试检查问题能否命中，适当降低相似度阈值或提高 TopK；
5. 智能体是否确实绑定了该知识库，以及智能体创建人对该知识库是否有使用权限。

## 模型网关

「管理 → 模型网关」仅超级管理员可见，集中管理平台使用的模型（大语言模型、向量模型、Rerank 模型、OCR 识别、Dify 知识引擎 5 个子页面均支持列表分页与每页条数记忆，顶部状态与策略下拉保持全量）：

### 大语言模型

- 内置 DeepSeek、通义千问、腾讯混元、字节豆包、智谱 GLM 等通道，也可以添加自定义的 OpenAI 兼容通道或自定义 HTTP 通道；
- 每个通道填写 Base URL、API Key、默认模型与可用模型列表，可以「测试连接」验证连通性；
- **默认通道**：智能体未指定模型时使用；**降级通道**：开启故障转移后，默认通道调用失败时自动切换；
- 可以设置超时时间与重试次数；
- **AI 助手**：可以在路由策略中为 AI 助手单独选择通道与模型（例如更便宜或工具调用更稳定的模型），不设置时跟随默认通道；专用通道不可用时自动回到默认通道。

没有启用且配置了 API Key 的通道时，智能体和 AI 助手都无法回答。

### 向量模型、OCR 与 Dify 知识引擎

- **Rerank 模型**：可选。平台内置引擎的知识库在混合检索下选择「Rerank 模型」排序时调用，全平台同时只生效一个，用哪个模型由生效的配置决定。没有生效的配置时，知识库不能选择这个排序方式，只能用权重设置。调用失败会自动退回融合排序。Dify 知识库的 Rerank 模型在 Dify 中配置；
- **向量模型（Embedding）**：平台内置引擎知识库的向量化依赖它，添加后需要激活，并建议先测试连接。接口地址填 OpenAI 兼容的 Base URL 时自动拼接 `/embeddings`；地址最后一段以 embeddings 结尾时（如 `/api/modelConfig/textEmbeddings`）按完整地址调用。不使用 API Key 的中转服务可以配置自定义请求头鉴权（如 `app_id`、`device_mac`），请求头加密保存，编辑时留空即保持不变；
- **OCR**：支持本地识别与在线识别两种方式，用于扫描件和图片文档；
- **Dify 知识引擎**：配置 Dify 服务地址与 API Key，用于 Dify 外部引擎知识库。

## 用户管理

「管理 → 用户」（仅超级管理员）：新建用户、修改角色、启用 / 停用账号、重置密码。停用的账号会被立即强制退出。「管理 → 角色与权限」展示三种角色的权限对照。

## 开放与安全

「管理 → 开放与安全」用于让外部系统调用智能体，并管理安全策略：

- **开放 API 凭证**：创建 API Key 时可以限定可调用的智能体范围、权限范围（scope）、IP 白名单、限流与配额；Key 明文只在创建时显示一次，支持轮换；
- **接入终端**：管理接入平台的客户端；
- **护栏策略**：敏感词过滤、个人信息（PII）脱敏、提示词注入检测，流式输出也会实时检查；
- **审计日志与告警**：记录关键操作与调用，可设置告警规则（如调用被拒绝率、高风险事件数）。

### 通过开放 API 调用智能体

1. 在「开放与安全」创建 API Key，授权要调用的智能体；
2. 请求 `POST /open/v1/chat-messages`，请求头 `Authorization: Bearer <API Key>`；
3. 请求体包含 `agentId`（智能体 ID 或编码）、`message`（用户问题）、`responseMode`（`streaming` 为 SSE 流式输出，其他值如 `blocking` 为一次性返回 JSON），可选 `conversationId` 续接多轮对话（若智能体开启了记忆压缩，早期对话摘要自动在服务端生效），可选 `inputs` 传入自定义提示词变量键值对；
4. 可选请求头：`X-End-User` 标识终端用户，`Idempotency-Key` 防止重复提交，`X-Request-Id` 便于排查。

## AI 助手

控制台和智能体调试台右下角的机器人按钮打开 AI 助手，可以停靠在右侧、悬浮或全屏。悬浮按钮支持**按住上下拖动**避让页面内容，鼠标悬停时可点击右上角按钮**贴边隐藏**为屏幕最右侧的极窄小耳朵（几乎不遮挡页面按钮），鼠标划过右侧边缘时会自动滑出「AI 助手」提示胶囊，点击即可打开对话或图钉恢复常驻显示。

- **执行模式**（默认）：助手可以查询你有权限的智能体、知识库及文档/FAQ（含图片与视频数量及外链）、MCP 服务与可用工具、技能库、模型通道状态与用量（含各模型分布排行），并可读取对话日志中的调用链路摘要来诊断智能体“无回复”或“回复慢/卡在哪里”；还可以帮你创建智能体、创建知识库、添加/修改 FAQ（支持附带联网图片与视频链接）、绑定知识库、修改提示词、启停智能体、为智能体创建开放 API 凭证。超级管理员还可以让助手实时测试某个模型通道。
- **问答模式**：只回答使用问题，不查询平台数据，回复更快。

创建或修改类请求不会直接执行：助手会生成一张**操作卡片**，展示将要执行的内容（修改类会展示修改前后对比），你点击「确认」后才会真正执行，10 分钟内有效。助手不提供删除资源、停用用户、修改角色、修改网关密钥等高危操作，这些需要在界面中完成。助手的权限与你在界面上的权限完全一致，所有执行的操作都会记录到审计日志。

助手知道你当前所在的页面：在调试台或知识库详情中，可以直接说"这个智能体为什么没回复""给这个知识库加一条 FAQ"。输入框上方会显示当前关联的资源，点「不关联」可以让这次提问不带上它。回复中的智能体、知识库名称可以点击跳转。

一句话可以包含多个步骤，例如"建一个知识库，再建一个客服智能体并把知识库绑定给它"：助手会生成多张卡片，后面的卡片依赖前面卡片创建的资源，需要按顺序确认，前一张确认成功后，后一张的确认按钮才可用。

通过助手创建开放 API 凭证时，Key 明文只在确认后的卡片中显示一次，请立即复制保存；助手本身看不到明文。

历史对话保留 90 天，可以在助手标题栏的时钟图标中查看、继续或删除。AI 助手自带**多轮上下文记忆与自动滚动压缩**：短对话（≤ 6 轮）直接保留原文、零额外开销；超过 6 轮的长排查对话会在每轮结束后**后台异步**把早期对话浓缩为结构化记忆摘要（保留智能体/知识库名称与 ID、已查明结论），顶部显示「已压缩早期 N 条对话记忆」并可点击展开查看，也支持点击标题栏的「压缩记忆」按钮手动立即压缩；在概览与调试页之间切换或刷新时会自动续接当前对话。

AI 助手支持**实时界面联动与跨页面操作（Live UI Co-pilot）**：
- **跨页面无缝跳转**：可直接对助手说“进入这个智能体的调试界面”“打开 XX 知识库”“切到模型网关”“返回智能体列表”，助手会直接切换页面并保持对话窗口打开、流式回复不中断，落地后自动切到目标子页签或高亮对应区块。
- **查找与筛选同步演示**：当你在控制台让助手“查找某个智能体 / 知识库 / FAQ / 场景模板 / 技能 / 工具 / 用户”时，界面会自动切换到对应模块，顶部弹出「AI 助手正在…」轻提示，搜索框出现发光定位并流畅键入关键词触发检索，随后闪烁高亮命中结果，就像助手在页面上帮你亲手操作一样。
- **调试页提示词电影级演播与草稿试聊**：在智能体调试页让助手优化、润色或修改系统提示词时，生成修改对比卡片的同时会**自动**平滑定位到左侧提示词框：依次呈现「蓝色全选原提示词 → 光标平滑清空旧内容 → 真实光标逐字写入新提示词（带实时进度条）」并保留「重播 / 撤回」操作条；右侧可直接试聊验证，满意后再点卡片的 **「确认修改」** 即刻保存上线并刷新提示词版本列表。
- **自定义变量弹窗实时填入保存**：在调试页让助手“新增/修改/删除自定义变量”（如门店名称、下拉选项、必填校验等）并确认后，助手会自动高亮点击 **「+ 添加」** 打开真实的 **「添加自定义变量」弹窗**，逐项聚焦并光标键入变量名、显示名称、类型、选项、默认值与输入提示，模拟点击 **「保存变量」** 后关闭弹窗、绿闪高亮新变量并自动展开右侧「变量表单」。
- **全模块 CRUD 真实弹窗演播与跨页联动**：无论你当前停留在哪个页面，确认助手生成的任何增删改操作卡片后（新建智能体、修改模型设置、关联/解绑知识库、新建知识库、调整知识库检索参数、新增/修改 FAQ、存为场景模板、新建技能、新建自定义 HTTP 工具、登记 MCP 服务、新建用户、签发开放凭证等），助手都会自动跨页切换到目标模块，模拟按压新建/编辑按钮打开真实弹窗、逐项光标填入内容（密码/密钥等敏感字段除外）、模拟点击保存后关闭弹窗并绿闪高亮最新条目。

## 常见问题

### 智能体调试时没有回复

1. 智能体是否为「已停用」状态；
2. 模型网关中是否有启用并配置了 API Key 的通道，通道测试连接是否成功，API Key 是否欠费或过期；
3. 智能体绑定的知识库是否已停用、被删除，或创建人对它的使用授权已被撤销（这种情况下对话会被直接拒绝）；
4. 查看智能体日志中的错误信息。

在 AI 助手的执行模式中说"帮我诊断一下 XX 智能体"，助手会自动完成以上检查。

### 回复很慢

先在调试页右上角打开 **「链路开」**（线上客户端问题可由超管在「构建 → 工具」临时打开 **「记录开放接口调用链路」**），重新提问后查看 **「调用链路」** 瀑布图，即可精确定位耗时卡在哪个环节（向量模型编码、混合召回、Rerank 重排、外部工具/联网搜索，还是大模型首字延迟 TTFT 与生成）。常见优化方式：关闭不必要的联网搜索与深度思考（FAQ 场景建议将思考模式设为 `OFF`）、适当降低输出上限或 Top K、减少记忆轮数，或在模型网关切换到响应更快的通道。也可以直接在 AI 助手执行模式里问"这个智能体为什么回复很慢"，助手会自动结合日志里的调用链路给出定位。

### 向量模型测试连接失败

检查 Base URL 与 API Key 是否正确、账号额度是否充足、模型名称是否是该服务支持的向量模型；测试成功后会自动识别向量维度。

### 开放 API 返回 401 或 403

401 表示 API Key 无效或已被撤销；403 通常是 Key 没有该智能体的调用权限、scope 不足，或来源 IP 不在白名单内。

## 配置项详细说明

下面列出各设置页的关键参数，均说明「是什么、取值范围、什么时候改」：

### 智能体模型与对话参数

| 参数 | 是什么 | 取值范围与默认 | 什么时候改 |
| --- | --- | --- | --- |
| **温度（temperature）** | 控制回答的随机性与创造性，越低越稳定保守，越高越发散 | `0.0`～`2.0`（默认 `0.7`） | 知识库客服、FAQ、数据查询建议调低到 `0.1`～`0.3`；文案与内容创作可调高到 `0.8`～`1.0` |
| **Top P（核采样）** | 按累计概率截断候选词，与温度共同影响多样性 | `0.0`～`1.0`（默认 `1.0`） | 一般保持默认，只调温度即可；避免同时把温度和 Top P 调得很极端 |
| **最大输出长度（maxTokens）** | 单次回答允许生成的最大输出 Token 数 | 正整数（模型上限以内，留空跟随通道默认） | 回答经常被截断时调大；只需简短回答或控制输出成本时调小（如 `512`～`1024`） |
| **上下文记忆轮数（memoryTurns）** | 多轮对话自动带入最近 N 轮历史问答 | `0`～`10` 轮（默认 `0` 关闭） | 一问一答的 FAQ/客服保持 `0` 最省 Token；需要连续追问的顾问/助手场景设为 `3`～`6` 轮（每多 1 轮约增加 300～500 输入 Token） |
| **记忆压缩（memoryCompression）** | 超出记忆轮数的早期对话后台异步浓缩为摘要 | 开启 / 关闭（默认关闭，仅开启上下文记忆时生效） | 长对话排障/咨询顾问（常超 8～10 轮）建议开启，既保留早期型号/背景信息又不拖慢首字；短问答保持关闭最省成本 |
| **思考模式（thinkingMode）** | 控制推理模型是否先输出内部思考链再作答 | `OFF`（默认关闭）/ `AUTO`（跟随模型默认）/ `ON`（开启） | FAQ 和知识库问答建议保持 `OFF`（首字更快、省 Token）；复杂推理、代码排障可改 `ON` 或 `AUTO` |
| **知识库使用方式（knowledgeMode）** | 决定智能体如何触发知识库检索 | `PRE_RETRIEVE`（先检索后回答，默认）/ `AGENTIC`（模型自主检索） | 绑定多篇文档或需要模型换关键词多次查时切到「模型自主检索」（要求通道支持工具调用，最多检索 3 次）；小模型通道保持「先检索后回答」 |
| **主备通道路由** | 为单个智能体指定专用主通道、模型和备用通道 | 跟随平台默认 / 自选已就绪通道 | 某智能体需要特定模型能力（如更强代码模型或更低成本模型）时单独指定；不设置则跟随网关全局默认策略 |

### 知识库切分与检索参数

| 参数 | 是什么 | 取值范围与默认 | 什么时候改 |
| --- | --- | --- | --- |
| **切片大小（chunkSize）** | 文档切分成单个切片的目标字符数 | 正整数（默认 `500` 字） | 问答零散、条款短小时调小（`300`～`400`）；长操作步骤需要完整上下文时调大（`800`～`1000`），改后需重建索引 |
| **切片重叠（chunkOverlap）** | 相邻两个切片首尾重叠的字符数，防止关键句被切断 | 小于切片大小（默认 `80` 字） | 经常出现半句话被截断导致查不全时适当调大（如 `100`～`150`） |
| **召回条数（Top K）** | 每次检索最终注入提示词的切片数量上限 | `1`～`20`（默认 `3`） | 回答信息不全时调大到 `5`～`8`；上下文窗口小或想省 Token 时调小到 `2`～`3` |
| **分数阈值（scoreThreshold）** | 过滤低相关性切片的最低得分门槛 | `0.0`～`1.0`（默认 `0.5`） | 检索不到内容时先在召回测试中观察得分并适当调低（如 `0.3`）；经常带入无关资料时调高 |
| **混合权重（向量 / 关键词权重）** | 混合检索中语义向量与 BM25 中文分词关键词的融合比例 | 两者之和为 `1.0`（默认 `0.5 : 0.5`） | 含大量产品型号、错误码、专有名词时提高关键词权重（如 `0.4 : 0.6`）；口语化语义问法为主时提高向量权重 |
| **Rerank 重排** | 对混合召回的候选切片用专门重排模型做二次精排 | 开启 / 关闭（需先在模型网关激活 Rerank 模型） | 对精度要求高、知识库文档较多时开启；追求最低延迟和零额外重排费用时关闭 |
| **语义缓存** | 缓存相近问题的检索结果，减少重复向量化与检索耗时 | 系统自动管理，支持在知识库详情手动清空 | 调整检索参数或更换向量/Rerank 模型后系统会自动清空，异常时也可手动点击清空 |

### 模型网关与工具全局参数

| 参数 | 是什么 | 取值范围与默认 | 什么时候改 |
| --- | --- | --- | --- |
| **支持工具调用（supportsTools）** | 标记模型通道是否支持 Function Calling | 布尔开关（预置云端通道默认开，Ollama/自定义默认关） | 确认本地 Ollama 或自定义通道支持工具调用后再打开；不支持工具调用的小模型必须保持关闭 |
| **上下文窗口（contextWindow）** | 通道单次请求允许的输入加输出总 Token 上限 | 正整数（留空不裁剪，Ollama 默认按 `4096` 保护） | 板子或本地小模型务必填写实际窗口（如 `4096`、`8192`），平台会自动预留输出并收缩历史与知识库内容；云端大模型可填 `65536` 或 `131072` |
| **超时时间与重试次数** | 单次模型 HTTP 调用超时毫秒数及失败重试次数 | 超时 ≥ `3000ms`（默认 `30000ms`）；重试 `0`～`3` 次（默认 `1`） | 推理模型或慢速本地模型经常超时时调大超时；需要快速切降级通道时调小重试次数 |
| **单次回答最多调用工具轮数** | 模型回答单个问题时最多连续发起几轮工具调用 | `1`～`10` 轮（默认 `5` 轮，在「构建 → 工具」顶部设置） | 复杂多工具串联不够用时调大；为控制延迟和工具费用时调小 |
