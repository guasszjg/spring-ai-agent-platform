# AgentMatrix 平台使用文档

本文档是 AgentMatrix 企业级智能体平台的使用说明，供平台内置的 AI 助手检索后回答使用问题。
界面左侧菜单分为四组：监控（概览）、构建（智能体、场景模板、工具）、数据（知识库）、管理（模型网关、用户、角色与权限、开放与安全）。

## 角色与权限

平台有三种角色：

- **超级管理员**：拥有全平台权限，包括模型网关、用户管理、角色与权限、开放与安全等治理功能，可以管理系统公共资源。
- **开发者**：可以创建、调试并管理属于自己的智能体、知识库与场景模板；可以使用系统公共资源和别人授权给自己的资源。
- **只读观察员**：只能查看被授权的智能体与知识库的元数据和监控指标，不能创建、编辑、调试。

「用户」和「角色与权限」菜单仅超级管理员可见。新建用户或重置密码后，用户首次登录需要先修改临时密码，临时密码过期后需联系管理员重新重置。

资源分为三类归属：我创建的（我的）、系统公共（超级管理员创建，所有人可见可用）、他人共享给我的（通过授权获得查看、运行或使用权限）。系统公共智能体只有超级管理员可以修改，开发者可以点击「复制」得到一份属于自己的副本再修改。

## 概览

「监控 → 概览」展示当前账号范围内的用量：超级管理员看全站数据，其他角色看本人创建的智能体与本人的 AI 助手对话。

- Token 总量、输入 / 输出 Token、估算成本，可切换今天、近 7 天、近 30 天；
- Token 趋势、模型占比、调用排行、按分类的平均响应时延。

AI 助手自身消耗的 token 也计入概览的用量与成本。

## 智能体

### 创建智能体

在「构建 → 智能体」点击新建，填写：

- **名称**与**唯一业务编码（code）**：编码在全平台唯一，开放 API 调用时可以用编码指定智能体；
- **分类**：代码研发、运维架构、产品策划、知识库客服、数据分析、内容创作、通用智能；
- **模型**：可以选择模型网关中的模型，不选择时跟随网关的默认通道；
- **系统提示词（System Prompt）**：定义智能体的角色、能力边界与回答风格；
- 温度（temperature）、描述、标签等。

也可以从「场景模板」一键套用行业模板创建，再按需修改。

### 智能体列表

列表支持按范围（全部 / 我的 / 系统公共）、分类、运行状态和关键词筛选，提供卡片与列表两种视图。卡片上可以调试、编辑、复制、启停，并显示累计调用次数和平均响应耗时。点击智能体 ID 可以一键复制，开放 API 调用时需要用到。

智能体只有三种状态：**运行中**、**空闲中**、**已停用**。已停用的智能体不能被调用，包括通过开放 API 的请求。在卡片上点击启停按钮即可切换。

### 编排与调试

在智能体卡片上点击「调试」进入编排与调试页面，左侧是编排区，右侧是调试预览：

- **提示词**：编辑系统提示词，支持 AI 自动生成或优化；
- **变量**：提示词中可以使用 `{{input}}`（用户输入）、`{{system_time}}`（当前时间）等变量；
- **知识库**：绑定一个或多个知识库，对话时自动检索相关内容注入上下文；
- **工具**：开启时间工具、联网检索、自定义 HTTP 工具等，模型会按需自动调用；
- 右侧调试区可以直接对话，显示工具调用过程、响应耗时与 token 消耗。

### 日志与监控

在智能体上可以查看调用日志（每次对话的输入、输出、模型与耗时）和监控统计（调用量、成功率、耗时趋势）。智能体"没有回复"或"回答不对"时，先看日志中失败的对话和错误原因。

## 场景模板

「构建 → 场景模板」提供按行业预置的智能体模板（包含名称、分类、系统提示词、模型参数等）。选择模板可以一键创建智能体。开发者也可以创建自己的模板，超级管理员可以维护系统公共模板。

## 工具

「构建 → 工具」管理所有智能体共用的平台工具：

- **时间工具**：获取当前时间、时区转换、时间戳转换、星期计算等；
- **联网检索（博查搜索）**：用于查询最新新闻、实时天气等互联网信息，需要配置博查 API Key；
- **自定义 HTTP 工具**：填写请求地址、方法、参数说明，让智能体调用你自己的业务接口。

工具在这里统一维护，在智能体编排页中按需开启。

## 知识库

「数据 → 知识库」管理企业私有知识，智能体绑定后回答时会检索知识库内容。

### 两种引擎

- **平台内置引擎**：文档在平台本地解析、切片、向量化，支持向量 + 关键词混合检索、父子分块、语义缓存。**必须先在「模型网关 → 向量模型」中配置并激活一个向量模型**，否则只能做字符级近似匹配，语义检索效果很差。
- **Dify 外部引擎**：文档存放在外部 Dify 服务中。需要先在「模型网关 → Dify 知识引擎」中配置地址与 API Key 并测试连接成功，才能创建 Dify 知识库。

### 文档与 FAQ

- 支持上传 Markdown、PDF、DOCX、TXT、HTML、CSV、XLSX 等格式，每批最多 5 个文件、单个文件不超过 15MB；扫描件与图片可通过 OCR 识别。
- 可以维护 FAQ（高频问答对），问答对会优先命中，适合客服场景。
- 提供召回测试：输入一个问题，查看能检索到哪些切片及其得分，用于调整检索参数（TopK、相似度阈值、向量与关键词权重）。

### 检索不到内容时的排查

1. 知识库是否为空（没有文档也没有 FAQ）；
2. 平台内置引擎：是否已激活向量模型，向量模型最近一次测试连接是否成功，更换向量模型后是否重建过索引；
3. Dify 引擎：Dify 知识引擎是否配置并测试连接成功；
4. 用召回测试检查问题能否命中，适当降低相似度阈值或提高 TopK；
5. 智能体是否确实绑定了该知识库，以及智能体创建人对该知识库是否有使用权限。

## 模型网关

「管理 → 模型网关」仅超级管理员可见，集中管理平台使用的模型：

### 大语言模型

- 内置 DeepSeek、通义千问、腾讯混元、字节豆包等通道，也可以添加自定义的 OpenAI 兼容通道或自定义 HTTP 通道；
- 每个通道填写 Base URL、API Key、默认模型与可用模型列表，可以「测试连接」验证连通性；
- **默认通道**：智能体未指定模型时使用；**降级通道**：开启故障转移后，默认通道调用失败时自动切换；
- 可以设置超时时间与重试次数；
- **AI 助手**：可以在路由策略中为 AI 助手单独选择通道与模型（例如更便宜或工具调用更稳定的模型），不设置时跟随默认通道；专用通道不可用时自动回到默认通道。

没有启用且配置了 API Key 的通道时，智能体和 AI 助手都无法回答。

### 向量模型、OCR 与 Dify 知识引擎

- **向量模型（Embedding）**：平台内置引擎知识库的向量化依赖它，添加后需要激活，并建议先测试连接；
- **OCR**：支持本地识别与在线识别两种方式，用于扫描件和图片文档；
- **Dify 知识引擎**：配置 Dify 服务地址与 API Key，用于 Dify 外部引擎知识库。

## 用户管理

「管理 → 用户」（仅超级管理员）：新建用户、修改角色、启用 / 停用账号、重置密码。停用的账号会被立即强制退出。「管理 → 角色与权限」展示三种角色的权限对照。

## 开放与安全

「管理 → 开放与安全」用于让外部系统调用智能体，并管理安全策略：

- **开放 API 凭证**：创建 API Key 时可以限定可调用的智能体范围、权限范围（scope）、IP 白名单、限流与配额；Key 明文只在创建时显示一次，支持轮换；
- **接入终端**：管理接入平台的客户端；
- **护栏策略**：敏感词过滤、个人信息（PII）脱敏、提示词注入检测，流式输出也会实时检查；
- **审计日志与告警**：记录关键操作与调用，可设置告警规则（如调用被拒绝率、高风险事件数）。

### 通过开放 API 调用智能体

1. 在「开放与安全」创建 API Key，授权要调用的智能体；
2. 请求 `POST /open/v1/chat-messages`，请求头 `Authorization: Bearer <API Key>`；
3. 请求体包含 `agentId`（智能体 ID 或编码）、`message`（用户问题）、`responseMode`（`streaming` 为 SSE 流式输出，其他值如 `blocking` 为一次性返回 JSON），可选 `conversationId` 续接多轮对话；
4. 可选请求头：`X-End-User` 标识终端用户，`Idempotency-Key` 防止重复提交，`X-Request-Id` 便于排查。

## AI 助手

控制台和智能体调试台右下角的机器人按钮打开 AI 助手，可以停靠在右侧、悬浮或全屏。

- **执行模式**（默认）：助手可以查询你有权限的智能体、知识库、模型通道状态与用量，诊断智能体问题；还可以帮你创建智能体、创建知识库、添加 FAQ、绑定知识库、修改提示词、启停智能体、为智能体创建开放 API 凭证。超级管理员还可以让助手实时测试某个模型通道。
- **问答模式**：只回答使用问题，不查询平台数据，回复更快。

创建或修改类请求不会直接执行：助手会生成一张**操作卡片**，展示将要执行的内容（修改类会展示修改前后对比），你点击「确认」后才会真正执行，10 分钟内有效。助手不提供删除资源、停用用户、修改角色、修改网关密钥等高危操作，这些需要在界面中完成。助手的权限与你在界面上的权限完全一致，所有执行的操作都会记录到审计日志。

助手知道你当前所在的页面：在调试台或知识库详情中，可以直接说"这个智能体为什么没回复""给这个知识库加一条 FAQ"。输入框上方会显示当前关联的资源，点「不关联」可以让这次提问不带上它。回复中的智能体、知识库名称可以点击跳转。

一句话可以包含多个步骤，例如"建一个知识库，再建一个客服智能体并把知识库绑定给它"：助手会生成多张卡片，后面的卡片依赖前面卡片创建的资源，需要按顺序确认，前一张确认成功后，后一张的确认按钮才可用。

通过助手创建开放 API 凭证时，Key 明文只在确认后的卡片中显示一次，请立即复制保存；助手本身看不到明文。

历史对话保留 90 天，可以在助手标题栏的时钟图标中查看、继续或删除。

## 常见问题

### 智能体调试时没有回复

1. 智能体是否为「已停用」状态；
2. 模型网关中是否有启用并配置了 API Key 的通道，通道测试连接是否成功，API Key 是否欠费或过期；
3. 智能体绑定的知识库是否已停用、被删除，或创建人对它的使用授权已被撤销（这种情况下对话会被直接拒绝）；
4. 查看智能体日志中的错误信息。

在 AI 助手的执行模式中说"帮我诊断一下 XX 智能体"，助手会自动完成以上检查。

### 回复很慢

联网检索等工具会增加耗时；输出上限（max tokens）过大、系统提示词过长也会变慢。可以关闭不需要的工具、适当降低输出上限，或在模型网关中切换到响应更快的通道。

### 向量模型测试连接失败

检查 Base URL 与 API Key 是否正确、账号额度是否充足、模型名称是否是该服务支持的向量模型；测试成功后会自动识别向量维度。

### 开放 API 返回 401 或 403

401 表示 API Key 无效或已被撤销；403 通常是 Key 没有该智能体的调用权限、scope 不足，或来源 IP 不在白名单内。
