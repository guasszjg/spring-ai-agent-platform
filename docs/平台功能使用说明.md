# 平台功能使用说明

给平台管理员、运营人员看：控制台各模块管什么、怎么配置、哪些设置会影响效果和成本。

---

## 1. 模型网关（仅超级管理员）

侧边栏「管理 → 模型网关」展开后有四个子页面，每个子页面后的状态点含义：绿色正常，橙色需要处理，灰色未启用（可选项）。

### 1.1 大语言模型

智能体对话使用的模型通道。

| 设置 | 作用 |
|---|---|
| 通道 | 每个通道对应一个模型服务商：内置 DeepSeek、通义千问、腾讯混元、字节豆包，也可以添加自定义通道（OpenAI 兼容协议或自定义 HTTP）。密钥加密存储 |
| 调度开关 | 关闭的通道不参与路由 |
| **默认通道** | 所有智能体对话默认走这个通道 |
| **降级备用** | 默认通道调用失败时改用的通道 |
| **自动故障转移** | 勾选后，失败时才会切到降级备用通道；不勾选则直接报错 |
| **AI 助手** | 平台内置 AI 助手专用的通道和模型，可选更便宜、工具调用更稳的模型；不设置则跟随默认通道 |

**选路顺序**：默认通道 → 与智能体指定模型匹配的就绪通道 → 任意一个就绪通道。超时和重试次数在通道上设置，未设置时用全局默认值（30 秒）。

**自定义通道的附加配置**（「配置」弹窗里的自定义配置 JSON）：

- `headers`：用自定义请求头鉴权，代替 `Authorization: Bearer`（例如中转服务要求的 `app_id`）。
- `"webSearch": true`：该通道默认开启服务端联网搜索。

> 注意：接口地址包含特定中转路径、或「`deepseek-v4-flash` + 自定义请求头鉴权」的通道，平台会**强制开启联网搜索**。实测联网会让需要整理资料的问答慢 3～5 秒、输入 Token 多 2000～6000，知识库问答类场景不需要联网。

### 1.2 向量模型

自建知识库切片向量化与语义检索使用的 Embedding 模型。

- 全平台**同时只生效一个**。
- 支持 OpenAI 兼容的 `/v1/embeddings` 接口。如果填的是完整接口地址（最后一段以 `embeddings` 结尾），平台会原样调用。也支持用自定义请求头鉴权。
- **更换向量模型后，已入库的文档需要重新索引**，否则新旧向量不可比，检索会失准。
- 没有激活向量模型时，平台会降级为内置的简易特征投影，语义检索效果明显变差。正式使用前务必激活一个向量模型。

### 1.3 OCR 识别

识别扫描版 PDF 和图片里的文字。**可选**：不配置时，扫描件和图片标记为待识别，不影响其他文档入库。

### 1.4 Dify 知识引擎

对接外部 Dify 实例，在平台内管理 Dify 知识库。**可选**：不用 Dify 可以不配置。接入后（或库里已有 Dify 知识库时）侧边栏才出现「Dify 知识库」；新建 Dify 知识库要求引擎已通过连通性测试。

## 2. 知识库

### 2.1 两种引擎

| | 自建知识库 | Dify 知识库 |
|---|---|---|
| 解析、切片、向量化 | 平台自己完成 | 交给 Dify |
| 向量模型 | 模型网关里生效的向量模型 | Dify 中配置的模型 |
| 前提 | 激活一个向量模型 | 在模型网关接入 Dify 并测试通过 |
| 支持格式与限制 | 见下表 | 以 Dify 为准 |

### 2.2 支持的文件格式（自建知识库）

单个文件不超过 **15 MB**，一次最多上传 **5 个**文件。

| 格式 | 处理方式 |
|---|---|
| TXT、MD、MDX、MARKDOWN、VTT、PROPERTIES | 纯文本，自动识别 UTF-8 / GBK 编码 |
| PDF | 提取文字层；每页文字过少时判定为扫描件，需配置 OCR |
| DOCX | 按原顺序读取段落和表格；页眉保留，页码页脚丢弃 |
| XLSX、XLS | 逐个工作表读取，表头与数据行配对；公式取计算结果；隐藏工作表跳过 |
| CSV | 表头与每行配对，支持带引号的字段 |
| HTML、HTM | 去掉脚本、样式，保留标题层级、列表和表格文字 |

其他格式（旧版 `.doc`、`.pptx`、图片、JSON 等）上传时会被拒绝。`.doc` 请另存为 `.docx`；图片里的文字可先转成 PDF，并配置 OCR。损坏或无法读取的文件会生成一条说明切片，而不是把乱码入库。

### 2.3 检索设置

- 切片默认每段 500 字、重叠 80 字。
- 检索方式默认**混合检索**（向量 + 关键词），召回数 Top K 默认 3，相似度阈值默认 0.5。
- 知识库详情里的「检索测试」可以输入问题，查看实际召回的片段。调整提示词之前先确认召回是否正确。
- **FAQ（精准问答对）**：对固定问题，录入 FAQ 比上传文档更准。

### 2.4 绑定到智能体

在智能体调试页「知识库」区域添加。对话时平台先检索绑定的知识库，再把召回片段放进系统提示词，一起发给模型。这部分内容会计入输入 Token。

## 3. 智能体

### 3.1 状态

| 状态 | 说明 |
|---|---|
| 运行中 | 可以被开放接口调用 |
| 空闲中 / 已停用 | 开放接口调用返回 `agent_not_running` |

### 3.2 调试页（编排）

- **系统提示词**：左侧编辑的是**草稿**，右侧「调试预览」用草稿对话；点「发布上线」后才成为线上提示词。
- **版本管理**：「版本」按钮可以查看历史版本、对比差异、回滚。每次发布都会记录版本，可以附发布说明。
- **变量**：`{{input}}`（用户输入）、`{{system_time}}`（当前时间）可写进提示词。
- **知识库**：绑定 / 解绑知识库。
- **工具**：时间类工具（当前时间、星期计算、时区换算、时间戳转换、日期计算）、联网搜索，以及在「工具」页面定义的 HTTP 工具。联网搜索有两种，同一智能体选一种即可：
  - **DeepSeek 联网搜索**：约 0.005 元/次，默认使用模型网关里 DeepSeek 通道的 Key，无需单独申请；返回的长摘要更完整，交给模型的 Token 更多。
  - **博查联网搜索**：约 0.036 元/次，需要在「工具」页面填写博查 Key。
- **工具调用统计**：「工具」页面每个工具都显示今日 / 本月调用次数，点开可看累计次数、成功率、平均耗时、近 14 天趋势、按智能体拆分，以及按单价估算的本月费用（单价在工具配置里填写，失败的调用不计费）。超级管理员看全平台，其他用户只看自己可见的智能体。
- **单次回答最多调用工具轮数**（「工具」页面顶部，默认 5 轮，可调 1～10）：只限制模型回答**一个问题**时反复调用工具，不限制提问次数；到上限后模型会根据已查到的资料直接作答。
- **模型设置**（右上角滑块图标）：

| 设置 | 保存到哪里 | 影响范围 |
|---|---|---|
| 温度、最大标记、Top P | 智能体 | 调试与线上 |
| **上下文记忆**（0～10 轮，默认关闭） | 智能体 | 调试与线上（开放接口） |
| **思考模式**（跟随模型默认 / 关闭 / 开启） | 智能体 | 调试与线上（开放接口） |
| 联网搜索等其余开关 | 仅当前浏览器 | **只影响调试页**，线上调用不读取 |

线上调用时，联网搜索由通道配置决定（见 1.1）。思考模式选「跟随模型默认」时不传参数，由模型决定（DeepSeek V4 默认会思考）；选「关闭」首字更快、更省 Token。部分中转通道会忽略这个开关。

### 3.3 访问 API

- 显示能调用此智能体的开放凭证。「共 N 条凭证可调用」可展开全部，包括专属于此智能体的和不限智能体的。
- 「重新生成」：已有专属凭证时**轮换**（旧 Key 24 小时内仍可用）；没有时签发一条只限此智能体、只有对话权限的凭证。
- 明文 Key 只在签发当下显示一次。

### 3.4 日志与监控

- 「日志」：每次对话的问题、回答、模型、耗时和 Token。
- 「监控」：调用量、延迟、Token 趋势。

## 4. 成本与延迟参考

一次带知识库的问答，输入约 1500～4000 Token（系统提示词 + 知识库片段 + 历史 + 联网结果），输出约 100～500 Token（含思考）。

影响最大的几项：

| 因素 | 影响 |
|---|---|
| 联网搜索 | 输入多 2000～6000 Token，慢 3～5 秒 |
| 上下文记忆 | 每多 1 轮，输入多 300～500 Token |
| 知识库召回数（Top K） | 每多一段，输入多几百 Token |
| 思考模式 | 输出变长，延迟增加；FAQ、知识库问答类智能体建议关闭 |
| 回答长度 | 输出单价通常是输入的数倍 |

## 5. AI 助手

右下角入口，可以用自然语言查询平台状态、创建智能体和知识库、录入 FAQ、绑定知识库、修改提示词、签发凭证等。**所有写操作都先生成确认卡片，由你确认后才执行**。

## 6. 开放与安全

| 页面 | 作用 |
|---|---|
| 风险总览 | 安全事件与风险概况 |
| 接入文档 | 开放接口的字段说明与在线调试 |
| 开放凭证 | 签发、轮换、停用、吊销凭证，详见《开放接口接入指南》 |
| 接入终端 | 登记、审批终端设备 |
| 用量统计 | 按开发者、凭证、终端统计调用与 Token |
| 护栏策略 | 输入 / 输出敏感词、终端管控模式、默认限流、调用时段、紧急停用、最大历史轮数 |
| 审计日志 | 凭证、终端、调用拦截等安全事件 |
| 账号对接 / 告警规则 | 外部身份对接与告警 |
